# И5. Агент-рилсмейкер

## Команда

Константин Богатырев, Артур Данилян.

## Задача

У владельца продукта есть посты и темы, но нет коротких видео. Агент из поста или темы
делает сценарий вертикального ролика на 20–45 секунд: зацепка, сцены с таймингом, текст на
экране, закадровый текст, подсказки по видеоряду, призыв к действию, и выгружает его в
формат, который можно отдать монтажёру или видеосервису. Человек проверяет сценарий до
съёмки, агент не публикует и само видео не генерирует.

## Вход

1. Описание продукта и аудитории.
2. Пост или тема как сырьё.
3. Команды в диалоге, например: «сделай ролик из поста 7 на 30 секунд», «короче», «сделай акцент на цене».
4. По желанию пакет из десяти постов для фоновой генерации.

## Выход

1. Сценарий ролика в JSON и Markdown: тема и исходный пост, зацепка, длительность,
сцены вида «секунды 0–5: на экране …, голос …», надписи, подсказки по видеоряду, призыв,
полный текст озвучки.
2. Результат проверки тайминга и флаги риска.
3. Библиотека из 10 и более сценариев со статусами проверки.

## Стек технологий

- Python 3.11+.
- LLM через прокси курса (OpenAI-совместимый API), модель на выбор команды.
- Логирование вызовов инструментов: файл, SQLite или Langfuse.
- pytest для тестовых кейсов.
- Проверка тайминга и темпа речи: чистый Python.
- Шаблоны сценариев: как данные в YAML или JSON, а не код.
- Библиотека сценариев: SQLite или файлы.
- Интерфейс: консоль или простой веб-чат.
- Не требуется: генерация видео, озвучка, монтаж, публикация.

## Данные

Данные команда собирает сама и хранит локально в `data/`:

- описание продукта и аудитории;
- 10–30 постов или тем как сырьё: свои тексты или тексты из открытых каналов;
- по желанию расшифровки 10–20 чужих коротких роликов по теме, чтобы инструмент статистики
  знал типичную длительность, число сцен и темп речи. Хранить как Markdown с таймкодами.

Сценарий не содержит дословных кусков чужих роликов и постов; проверка входит в тесты.
