# П6. Подписка на отклонение прогноза от плана

## Команда

Алексей Иванченко.

## Задача

Руководитель направления подписывается в Telegram на дорогу, станцию или клиента. Агент по
расписанию строит собственный прогноз суточной выгрузки на ближайшие дни, сравнивает его с
планом и фактом и присылает сообщение, только когда отклонение выходит за порог: «по дороге
ДОЛ прогноз на неделю на 18 % ниже темпа, который задаёт месячный план». В чате можно
спросить, из чего сложилось отклонение.

## Вход

1. Команды подписки в Telegram: срез (дорога, станция или клиент), горизонт, порог.
2. Вопросы в чате «почему».
3. По расписанию: витрины факта, плана и штатного прогноза на текущее «сегодня».

## Выход

1. Уведомление в Telegram, когда срез выходит за порог, с цифрами прогноза, плана и
факта.
2. Ответ на «почему» с разложением отклонения по составляющим.
3. Журнал пересчётов.

## Стек технологий

- Python 3.11+.
- LLM через прокси курса (OpenAI-совместимый API), модель на выбор команды.
- Логирование вызовов инструментов: файл, SQLite или Langfuse.
- pytest для тестовых кейсов.
- Модель суточной выгрузки: scikit-learn.
- Агрегаты по витринам: pandas.
- Бот: aiogram.
- Фоновый воркер: APScheduler или цикл с расписанием.
- Подписки и последнее отправленное состояние: SQLite.
- Не требуется: веб-дашборд.
