# Данные для итоговых проектов

По папке на каждый проект, файлы данных всегда в подпапке `data/`. В каждой папке README по одной структуре: команда, задача, вход,
выход, стек технологий, данные, и четыре раздела, которые команда заполняет сама в своём
описании решения: память, инструменты, контекст, управление рассуждением. Папку отдают
команде целиком вместе с брифом и картой данных `teacher/projects-data.docx`.

Единственный источник данных — витрины набора курса `data/dataset_student`. Всё, что лежит
здесь, из них выведено скриптом `derive_project_data.py`: станции, клиенты, грузы, числа
вагонов и даты взяты из витрин как есть, придумано только оформление файлов.

| Папка | Проект | Команда | Файлы |
|---|---|---|---|
| `p2-batch-normalize/` | П2. Ночная пачка реестров | Сапрошин, Матвеенко | `data/`: 20 реестров Excel, справочник станций |
| `p3-telegram-files/` | П3. Файл с заявками в Telegram | Кузьмина, Кирмель | `data/`: те же 20 реестров и справочник |

| `p6-forecast-subscription/` | П6. Подписка на отклонение прогноза | Иванченко | `data/`: копии витрин выгрузки, плана, штатного прогноза и манифеста |
| `i3-blogger/` | И3. Агент-блогер | Кружалин, Редих | `data/` пустая: команда собирает сама |

## Пересобрать

```bash
unzip -n data/dataset_student.zip -d data/
python3 teacher/projects-data/derive_project_data.py
```

Около десяти секунд. Скрипт пишет только в папки П2–П4 и сам удаляет старые реестры; README
и папки П6, И3, И5, С1 он не трогает (С1 написана руками и проверена парсером pglast).
П1 не назначен; его папка с письмами собирается только по флагу `--with-letters`. Результат детерминирован (seed 42), xlsx отличаются
только временем создания внутри файла.

Эталоны для проверки работ (разбор реестров, таблица раскладок, статистика П4, факты по
процедурам С1) студентам не отдаются: они лежат в `.scratch/2026-10-19-project-keys/` и
пересобираются флагом `--with-keys`.
